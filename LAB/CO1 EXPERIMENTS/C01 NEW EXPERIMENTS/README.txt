CSA47 - DEEP LEARNING: PYTHON EXPERIMENTS
==========================================

This ZIP contains 18 independent Python programs, one for each experiment in the
provided list (Experiments 1-18).

Requirements:
    Python 3.9+
    numpy
    pandas
    scikit-learn
    matplotlib

Install dependencies:
    pip install numpy pandas scikit-learn matplotlib

Run an experiment:
    python experiment_01_vectors.py
    python experiment_02_matrices.py
    ...
    python experiment_18_polynomial_regression.py

Notes:
- Each program is self-contained and uses sample data so it can run immediately.
- Some experiments print numerical results; plots (where relevant) are displayed
  using Matplotlib.
- The examples are educational demonstrations. Replace sample data with your
  own dataset when required by your instructor.
